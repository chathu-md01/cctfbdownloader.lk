# CCT FB DOWNLOADER 🚀
An ultra-premium, futuristic 3D Facebook Video Downloader.

## ⚙️ Prerequisites
1. **Node.js** (v18 or higher) installed on your system.
2. **yt-dlp** installed globally on your server/machine. 
   - Windows: `winget install yt-dlp` or download from [GitHub](https://github.com/yt-dlp/yt-dlp)
   - macOS: `brew install yt-dlp`
   - Linux: `sudo apt install yt-dlp`
